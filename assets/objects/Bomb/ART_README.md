# PNG nghệ thuật — Bomb

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ Java 2D hiện tại vẫn chạy.

Tên ảnh được nhận:
- Bomb.png

Kích thước khuyến nghị: 38 × 38 px (1x) hoặc 76 × 76 px (2x HD), PNG nền trong suốt, mũi bom chúc chéo xuống góc dưới-trái (7h–8h).
