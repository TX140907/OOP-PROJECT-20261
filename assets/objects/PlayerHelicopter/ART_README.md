Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ Java 2D hiện tại vẫn chạy.

Tên ảnh được nhận:
- PlayerHelicopter.png (204 × 104 px / 408 × 208 px)
- PlayerHelicopter_rescue.png (tùy chọn, dùng cho cảnh đón Thắng)

Nên dùng PNG nền trong suốt, đầu trực thăng hướng sang phải (+X).
