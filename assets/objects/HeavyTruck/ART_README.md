# PNG nghệ thuật — HeavyTruck

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng một mục dưới đây; nếu chưa có ảnh, phần vẽ Java hiện tại vẫn chạy.

Tên ảnh được nhận:
- HeavyTruck.png

Kích thước khuyến nghị: ~136 × 172 px (xe tải hạng nặng chiếm trọn bề ngang 1 làn đường). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
