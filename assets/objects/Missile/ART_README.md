# PNG nghệ thuật — Missile

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ Java 2D hiện tại vẫn chạy.

Tên ảnh được nhận:
- Missile.png

Kích thước khuyến nghị: 26 × 10 px (1x) hoặc 52 × 20 px (2x HD), PNG nền trong suốt, đầu tên lửa hướng sang phải (+X).
