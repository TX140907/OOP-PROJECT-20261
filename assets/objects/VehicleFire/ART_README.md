# PNG nghệ thuật — VehicleFire (Hiệu ứng Xe Bốc Lửa)

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ ngọn lửa Java 2D hiện tại vẫn chạy.

Tên ảnh được nhận:
- VehicleFire.png

Kích thước khuyến nghị: ~76 × 96 px (ngọn lửa bốc lên quanh xe khi đi sát lề đường quá 3 giây; game tự động co giãn nhịp nhàng và làm mờ dần khi thoát lề đường). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
