# PNG nghệ thuật — Pothole

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ Java hiện tại vẫn chạy.

Tên ảnh được nhận:
- Pothole.png

Kích thước khuyến nghị: ~44 × 28 px (ổ gà sụt lún asphalt, viền nứt nẻ, vũng nước đọng). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
