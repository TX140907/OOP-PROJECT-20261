# PNG nghệ thuật — FreezeEffect (Hiệu ứng Đóng Băng Xe Màn 3)

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ băng giá Java 2D hiện tại vẫn chạy.

Tên ảnh được nhận:
- FreezeEffect.png

Kích thước khuyến nghị: ~56 × 88 px (lớp sương băng bao quanh xe khi trúng gió mùa lạnh ở Màn 3). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
