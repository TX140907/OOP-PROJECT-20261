# PNG nghệ thuật — ConstructionBarrier

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ Java hiện tại vẫn chạy.

Tên ảnh được nhận:
- ConstructionBarrier.png

Kích thước khuyến nghị: ~68 × 36 px (rào chắn công trình sọc đỏ trắng, đèn cảnh báo vàng). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
