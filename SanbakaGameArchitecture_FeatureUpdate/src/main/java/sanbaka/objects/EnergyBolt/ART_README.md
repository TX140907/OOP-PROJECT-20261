# PNG nghệ thuật — EnergyBolt

Đặt ảnh PNG ngay trong thư mục này, cạnh file Java. Game tự dùng ảnh nếu tên trùng một mục dưới đây; nếu chưa có ảnh, phần vẽ Java hiện tại vẫn chạy.

Tên ảnh được nhận:
- EnergyBolt.png

Ảnh được co giãn theo khung của đối tượng. Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
