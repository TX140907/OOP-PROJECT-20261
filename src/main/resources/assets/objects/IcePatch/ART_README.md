# PNG nghệ thuật — IcePatch

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ Java hiện tại vẫn chạy.

Tên ảnh được nhận:
- IcePatch.png

Kích thước khuyến nghị: ~88 × 54 px (vũng băng trơn trong suốt phản chiếu ánh sáng trên mặt đường Màn 3). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
