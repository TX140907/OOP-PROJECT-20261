# PNG nghệ thuật — StrayDog

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ Java hiện tại vẫn chạy.

Tên ảnh được nhận:
- StrayDog.png

Kích thước khuyến nghị: ~48 × 30 px (chó vàng chạy rông hướng sang phải, game tự lật ngang khi chạy từ phải sang trái). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
