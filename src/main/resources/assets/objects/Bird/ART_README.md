# PNG nghệ thuật — Bird (Chim cản đường bay trực thăng)

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ chim vỗ cánh Java 2D hiện tại vẫn chạy.

Tên ảnh được nhận:
- Bird.png

Kích thước khuyến nghị: ~60 × 48 px (chim bay hướng sang trái về phía trực thăng). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
