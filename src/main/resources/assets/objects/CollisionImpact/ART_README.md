# PNG nghệ thuật — CollisionImpact (Hiệu ứng Va Chạm Đẩy Lùi & Làm Chậm)

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ chấn động/khói Java 2D hiện tại vẫn chạy.

Tên ảnh được nhận:
- CollisionImpact.png

Kích thước khuyến nghị: ~72 × 88 px (hiệu ứng chấn động va chạm và khói giảm tốc quanh xe khi bị đâm đẩy lùi). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
