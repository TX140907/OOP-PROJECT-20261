# PNG nghệ thuật — NinjaLead

Đặt ảnh PNG ngay trong thư mục này. Game tự dùng ảnh nếu tên trùng mục dưới đây; nếu chưa có ảnh, phần vẽ Java hiện tại vẫn chạy.

Tên ảnh được nhận:
- NinjaLead.png

Kích thước khuyến nghị: ~28 × 62 px (xe Lead be/đỏ, áo chống nắng hoa nhí, mũ bảo hiểm rộng vành, khẩu trang hoa che kín mặt). Nên dùng PNG nền trong suốt. Khởi động lại game sau khi thay ảnh để nạp lại cache.
